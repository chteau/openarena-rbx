# openarena-rbx

A port of [OpenArena](https://openarena.ws) 0.8.8 to Roblox, built with
[rbx-native](https://github.com/chteau/rbx-native) and its MCP server.

The game code is a Luau port of OpenArena's gamecode (itself built on the
GPL release of Quake III Arena via ioquake3). The maps, models, textures and
sounds are OpenArena's own GPL assets, converted by the tools in `tools/`.
